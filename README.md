# world.execute(me); MV 配套代码

 B 站视频 [【Opus5.5 一句话生成 world.execute(me); mv （附对话过程记录）】](https://www.bilibili.com/video/BV1RHhU63ESq/) 的配套动画源码。 [动态壁纸版本已上传 Wallpaper Engine 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3808989186)。

![原版 16:9 截图](docs/preview-original-16x9.jpg)

## 使用
* 想用壁纸直接点 wallpaper engine 链接下载即可
* 想看动画代码的见仓库里的配套代码，用 `index.html` 创建网页壁纸。仓库不包含音乐：在本地项目目录放入自己的 `song.mp3`，或在浏览器中点“选择本地音乐”。中英歌词默认开启；由 gpt 生成的Claude 对话动画模拟默认关闭，可用页面左下角的开关或壁纸属性切换。浏览器地址加 `?claude=1` 可默认显示动画，加 `?lyrics=0` 可隐藏歌词。
仅供交流学习使用
